# Security policy

## Report a problem

Please do not open a public issue for a security problem.

Use [GitHub private vulnerability reporting](https://github.com/clowk-in/1billion/security/advisories/new) for this repository. Say what you found and how to reproduce it.

This repository is the website of 1billion. A problem in the service itself (the API, the console, the delivery of mail) goes to the same place: we move it to the right team. You can expect an answer in a few days, and we credit you if you want.
